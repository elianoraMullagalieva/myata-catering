# МЯТА — сайт кейтеринга: как доправить

## Где что лежит
Сайт статический: HTML + CSS + JS, без сборки. Каждая версия — отдельная папка со своим `index.html`.

| Папка | Адрес | Статус |
|---|---|---|
| корень (`index.html`) | https://elianoramullagalieva.github.io/myata-catering/ | v1 |
| `v2/` | …/myata-catering/v2/ | **не трогать** |
| `v3/`, `v4/`, `v5/` | …/v3/, …/v4/, …/v5/ | старые версии, сохранены |
| `v6/` | https://elianoramullagalieva.github.io/myata-catering/v6/ | **актуальная, правим её** |

Внутри `v6/`:
- `index.html` — вся разметка и тексты;
- `styles.css` — стили; новые правки дописываются в конец файла;
- `anim.js` — появление блоков при прокрутке, счётчики, кнопки-магниты;
- `lead.js` — поп-ап «Оставить заявку»/«Заказать»; `reviews.js` — отзывы и их поп-апы;
- `tasting.js` — дегустация; `menu5.js` — меню; `liquid.js` — эффект «воды» на фото;
- `assets/` — фото, видео, иконки.

## Как посмотреть локально
Открыть папку в VS Code → расширение Live Server → «Open with Live Server» на `v6/index.html`.
Или в терминале из папки сайта: `python3 -m http.server 8000` → http://localhost:8000/v6/

## Как опубликовать
Сайт живёт в GitHub-репозитории `elianoraMullagalieva/myata-catering` (GitHub Pages). Нужен доступ к репозиторию от Эли.
1. Склонировать репозиторий: `git clone https://github.com/elianoraMullagalieva/myata-catering.git`
2. Перенести правленые файлы из `v6/` этого архива (или править прямо в клоне).
3. Чтобы у посетителей не остались старые файлы в кэше — в `v6/index.html` поменять цифры после `?v=` у `styles.css` и `.js` (любое новое число).
4. `git add v6 && git commit -m "что поправили" && git push` — через 1–2 минуты изменения на сайте.

## Правила, которые нельзя нарушать
- Фото и видео **не сжимать** без согласования с Эли.
- Видео на первом экране не трогать.
- Галочки согласия в формах — **выключены по умолчанию** (152-ФЗ), форма не отправляется без галочки.
- У всех кнопок — острые углы.
- Проверять на ширинах 390 / 768 / 1366 / 1440 / 2560, не должно быть горизонтальной прокрутки.
- Новая крупная версия — новая папка (`v7/`), старые не трогаем.
